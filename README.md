# GrossLivingArea.com

Encyclopedia of ANSI Z765 square footage rules. Next.js on Vercel, no database.

- `lib/questions.js` holds every pillar and question page as data.
- Pillar pages: `/<pillar>`. Question pages: `/<pillar>/<question-slug>`.
- Monetization: display ads, MeasureFloorPlan banners, possible paid checklist.
